# Albion Pathfinder

Бесплатный сайт для поиска **кратчайшего пути между зонами Albion Online** с фильтром безопасности.

- Выбираете «откуда» и «куда» (или кликаете по зонам на карте).
- Указываете, через какие зоны можно идти: только синие, + жёлтые, + красные или любые.
- Получаете маршрут по шагам, число переходов и подсветку на карте.
- Порталы королевских городов в Outlands можно включать и выключать.
- Маршрутом можно поделиться: ссылка вида `.../#from=3004&to=4000&s=blue&p=1`.

Сервер не нужен — это статический сайт для GitHub Pages.

## Как запустить локально

Из-за загрузки `data/zones.json` страницу нельзя открыть просто двойным кликом. Запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и откройте <http://localhost:8000>.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Откуда берутся данные

Карта строится из файла `cluster/world.xml` в публичном дампе игровых файлов
[ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps).
Скрипт `tools/build_zones.py` превращает его в компактный граф `data/zones.json`:

```bash
git clone --depth 1 https://github.com/ao-data/ao-bin-dumps.git
python tools/build_zones.py ao-bin-dumps/cluster/world.xml data/zones.json
```

Workflow `.github/workflows/update-data.yml` делает это автоматически раз в неделю
и коммитит изменения, так что после патчей игры карта обновится сама.
Чтобы он мог коммитить, включите **Settings → Actions → General → Workflow permissions → Read and write permissions**.

### Что учитывается

| Цвет | Типы зон |
|---|---|
| синий | безопасные зоны и королевские города |
| жёлтый | PvP без полного лута |
| красный | полный лут, Caerleon |
| чёрный | Outlands, портальные города, Rest-города |

Каждый переход между соседними зонами стоит 1 шаг. Стартовая и конечная зона
разрешены всегда, даже если они опаснее фильтра, — сайт предупредит об этом.

### Что пока не учитывается

- Дороги Авалона (меняются каждый день).
- Туманы и Brecilien.
- Данжи, острова, хидауты.

## Структура

```
index.html                 страница
style.css                  оформление
app.js                     поиск пути (BFS) и карта
data/zones.json            граф зон (генерируется)
tools/build_zones.py       сборка графа из дампа
.github/workflows/         автообновление данных
```
